# Cloud Engineer Onboarding Checklist

## Week 1 — Access and Orientation

- [ ] Confirm identity and MFA setup
- [ ] Obtain AWS/cloud console access
- [ ] Obtain GitHub/repository access
- [ ] Obtain monitoring platform access
- [ ] Obtain ticketing system access
- [ ] Review team communication channels
- [ ] Review escalation path
- [ ] Review architecture overview

## Week 2 — Operations

- [ ] Shadow daily health checks
- [ ] Review common alerts
- [ ] Review incident process
- [ ] Review change-management process
- [ ] Review backup and recovery procedures
- [ ] Complete one supervised operational task

## Week 3 — Tooling and Automation

- [ ] Review CI/CD pipeline
- [ ] Review infrastructure-as-code repository
- [ ] Review common scripts and automation
- [ ] Practice reading logs and metrics
- [ ] Complete one small automation or documentation improvement

## Week 4 — Independent Validation

- [ ] Handle one low-risk task independently
- [ ] Complete a runbook walkthrough
- [ ] Demonstrate understanding of escalation rules
- [ ] Identify one documentation gap
- [ ] Review progress with team lead
